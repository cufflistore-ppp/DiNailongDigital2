Top Up Saldo

Top up tidak wajib. Kalau ada saldo cukup, order langsung potong saldo (tanpa QRIS). Kalau tidak ada saldo, bayar pakai QRIS. Top up via Wijaya Pay supaya nanti order lebih cepat.

Status / Riwayat Top Up

Wijaya Pay

Setelah klik bayar, Anda diarahkan ke gateway Wijaya Pay (QRIS / VA / e-wallet). Setelah pembayaran berhasil, saldo akan ditambahkan. Jika belum masuk dalam 5 menit, hubungi admin dengan bukti transfer.

Tarik saldo (DANA saja)

Penarikan hanya ke e-wallet DANA. Minimal Rp 2.000. Biaya admin 4% dipotong dari jumlah penarikan. Request masuk panel admin untuk diproses.
